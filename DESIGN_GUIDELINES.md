# Sushi Daijoubu desu ka? – Design

## My idea

A modern sushi restaurant website with Japanese anime style and some meme humor.

The name Daijoubu desu ka? means "Are you okay?" in Japanese. I chose it because it sounds funny as a restaurant name.

Want the website to be colorful and a little crazy in some places, but still clean and easy to use.

## Style

Anime, sakura flowers, Japanese landscapes and sunsets for the home page and some smaller details around the website.

Funny anime characters and expressions.

The menu should be simpler, with the food as the main focus.

## Logo and fonts

Use the Japanese restaurant name 大丈夫ですか？ as the logo.

The full name is SUSHI Daijoubu desu ka? with a question mark.

Simple fonts that are easy to read and work with Norwegian, English and Japanese characters.
Logo and text separate from the background pictures change them later.

## Home page

Large hero picture with an anime sushi chef, sakura and a Japanese sunset.

The restaurant name, buttons and other text will be added separately.

Small illustrated icons below the hero as navigation buttons.

## Navigation

For customers:

- Home
- Menu
- Cart / Order

For admin:

- Dashboard
- Menu
- Orders
- Edit home page

I want the pages to have the same basic layout so it's easy to find everything.

The admin pages can be simpler than the customer pages.

## Pictures

Separate pictures for the hero, other backgrounds and sushi dishes.

WebP for larger pictures and SVG for icons where it makes sense.

The sushi pictures match the ingredients in the menu.

## Layout

Website will work on phones and computers.

## Languages

Norwegian Bokmål will be the default language.

English option for the menu, buttons and other customer pages.

Japanese text will mainly be used for the restaurant name and some design details.
